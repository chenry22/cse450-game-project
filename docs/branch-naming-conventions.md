# Branch Naming Conventions
This document serves as a reference for naming conventions when creating new branches in this repo.

## Reference

| Prefix | Explanation |
|--- | --- |
| `feature/` | New game features |
| `bugfix/` | Bug patches |
| `docs/` | Documentation updates |
| `playtest/` | Code versions that were used for playtesting |

## Notes
It may also be worth considering nested prefixes like `feature/character/` or `feature/scene/` for more complex categories.
